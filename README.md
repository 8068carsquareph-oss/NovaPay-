# NovaPay

NovaPay is a modern digital wallet web application designed for secure digital payments and money transfers.

## Features

- User Registration & Login
- Firebase Authentication
- Wallet Dashboard
- QR Code Payments
- Send & Receive Money
- Transaction History
- Deposit & Withdrawal Requests
- KYC Verification
- Admin Dashboard
- Notifications
- Responsive Design
- Dark Mode

## Technology Stack

- React.js
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Hosting

## Security

- End-to-End Encryption
- Two-Factor Authentication
- Secure API
- Audit Logs
- Device Verification

## Future Features

- Virtual Visa Card
- Bank Integration
- Bills Payment
- Mobile Load
- Merchant Payment
- Cashback Rewards
